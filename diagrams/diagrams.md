 # Commit Guard — System Diagrams
This directory contains architecture and workflow diagrams for the Commit Guard diploma project.

The diagrams are written using Mermaid and are used to visualize system components, interactions, and data flows.

# Diagrams
|File|Description|
|---|---|
|chrome-extension-architecture.png|Shows the main Chrome/Edge extension components and their interaction with GitHub and the FastAPI backend.|
|chrome-extension-sequence.png|Illustrates the commit analysis workflow, from initiating analysis on GitHub to receiving and displaying results.|
